# Calculadora de margen de promoción

[**Abrir la calculadora web**](https://stephhiyagon.github.io/calculadora-margen-promocion/)

Ingresa las unidades facturadas en promoción, el precio neto y el margen bruto de cada modalidad, y el margen objetivo. La app calcula el mínimo de unidades a precio normal y muestra el margen bruto combinado.

El cálculo se realiza en el navegador. El código de la app está en [`docs/index.html`](docs/index.html).
